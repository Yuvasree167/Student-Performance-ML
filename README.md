# Student Performance Analysis Using Machine Learning

## Project Description
This project analyzes students' academic performance and learning
behavior using machine learning techniques.

## Objectives
- Analyze student performance and learning patterns.
- Classify students based on their performance.
- Group students with similar learning characteristics.
- Predict students' examination scores.

## Machine Learning Techniques
1. Classification
2. K-Means Clustering
3. Regression

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Dataset
The student performance dataset contains academic and learning-related
information used for machine learning analysis.

## Project Files
- `MACHINE_LEARNING_PROJECT.ipynb` - Notebook containing the project code and analysis.
- `student_performance.csv` - Dataset used for the analysis.

## How to Run
1. Open the notebook in Google Colab.
2. Upload `student_performance.csv` when prompted, if necessary.
3. Run the notebook cells in order.
4. Review the analysis and model results.

## Conclusion
This project uses machine learning to explore student learning patterns
and analyze academic performance.
